# MediaSift application icon

The MediaSift mark combines a photo frame and sieve into one compact symbol:
media enters the top, is carefully filtered, and leaves as an organized result.
It intentionally avoids deletion imagery because duplicate review defaults to
keeping files.

- `media-sift-icon.png` is the transparent 1024 px RGBA source used by eframe
  for the live window and taskbar icon.
- `media-sift-icon.ico` embeds 16, 20, 24, 30, 32, 36, 40, 48, 60, 64, 72, 80,
  96, 128, and 256 px images for Windows shell contexts. It is embedded in the
  executable and used by the NSIS installer.

The design follows Windows guidance: a direct metaphor, a singular element,
rounded front-facing geometry, a strong silhouette, no typography, minimal
layers, restrained color treatment, and explicit checks at small sizes on
light, dark, and accent backgrounds.
